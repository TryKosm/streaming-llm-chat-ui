# Llm Stream Chat

Streaming chat UI with SSE backend and TypeScript client.

[![CI](https://github.com/NotPBShaw/llm-stream-chat/actions/workflows/ci.yml/badge.svg)](https://github.com/NotPBShaw/llm-stream-chat/actions/workflows/ci.yml)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)

TypeScript project with a minimal streaming chat backend and browser frontend client.

## Quickstart

```bash
npm install
npm run build
npm test
npm start
```

Open the static client and connect to the SSE stream endpoint.

## Features

- Server-Sent Events endpoint for token streaming
- Lightweight static web client
- Integration tests for stream framing
- CI build and test checks
